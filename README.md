# appercutdevelopment.com

Company homepage for [Appercut Development](https://appercutdevelopment.com), served via GitHub Pages.

## Structure

A single static `index.html` — no build step, no dependencies.

## Deployment

Pushes to `main` deploy automatically via GitHub Pages. The `CNAME` file points the custom domain `appercutdevelopment.com` to this repo.
